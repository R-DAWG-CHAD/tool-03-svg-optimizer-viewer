# ✨ SVG Path Code Cleaner & Visual Viewer

A fast, zero-login, browser-based utility to sanitize, optimize, minify, scale, and preview SVG markup.

## 🚀 Key Features

- **Sanitizes SVG Code:** Strips Inkscape, Illustrator, Figma metadata, comments, DOCTYPE, and empty `<g>` containers.
- **Decimal Coordinate Rounding:** Configurable decimal precision (1, 2, or 3 places) to strip bloated trailing numbers.
- **Vector Scaler:** Easily resize SVG viewBox dimensions by 0.5x, 1.5x, or 2.0x.
- **Visual Preview Box:** Instant checkerboard rendering engine to inspect vectors in real-time.
- **File Drag & Drop:** Upload `.svg` files directly or paste inline XML code.
- **File Size Savings Gauge:** Displays original size, minified size, and percentage savings.
- **One-Click Export:** Copy clean SVG code or download optimized `.svg` file directly.
- **100% Private & Offline:** Zero server uploads; all processing runs locally inside your browser.
